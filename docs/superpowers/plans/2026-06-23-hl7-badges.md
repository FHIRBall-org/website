# HL7 Membership Badges Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add HL7 membership and accelerator logo badges to all three member surfaces: homepage cards (badge strip), members listing cards (divider row), and member detail pages ("Member of" section).

**Architecture:** Add an `orgLogos` array field to the member content schema, populate it on members who are HL7 members, then surface the logos on each UI surface conditionally (only render if the array is non-empty). The homepage card strip shows only items flagged `cardBadge: true` to avoid link-nesting violations; the other two surfaces show all logos.

**Tech Stack:** Astro v5, Tailwind CSS v4, Vitest (unit), Playwright (E2E)

## Global Constraints

- `orgLogos` field defaults to `[]` — members without it must render identically to today
- Homepage cards are wrapped in `<a>` — no nested `<a>` inside the badge strip; use `<span>` elements
- Badge images live in `public/images/org-logos/`; logo paths in frontmatter must start with `/images/org-logos/`
- Detail page "Member of" row is `flex-nowrap` with `overflow-x: auto` — never wraps
- Members listing badge row allows wrapping
- Commit after every task

  ```typescript
  describe('Member orgLogos Validation', () => {
    const memberFiles = readdirSync(membersDir).filter(f => f.endsWith('.md'));

    memberFiles.forEach((file) => {
      const content = readFileSync(join(membersDir, file), 'utf-8');
      const frontmatter = content.split('---')[1];

      if (!frontmatter.includes('orgLogos:')) return;

      describe(`${file}: orgLogos`, () => {
        it('should have at least one entry', () => {
          expect(frontmatter).toMatch(/orgLogos:\s*\n\s+- /);
        });

        it('should have a name field in each entry', () => {
          expect(frontmatter).toMatch(/- name:\s*.+/);
        });

        it('should have logo path under /images/org-logos/', () => {
          expect(frontmatter).toMatch(/logo:\s*["']?\/images\/org-logos\//);
        });

        it('should have a https url', () => {
          expect(frontmatter).toMatch(/url:\s*["']?https:\/\//);
        });

        it('should have cardBadge as true or false', () => {
          expect(frontmatter).toMatch(/cardBadge:\s*(true|false)/);
        });
      });
    });
  });
  ```

## Post-Implementation Notes

- **Adding logos:** Place image files (e.g. `hl7.png`, `hl7-davinci.png`) in `public/images/org-logos/`. Transparent-background PNG recommended.
- **Tagging members:** Add `orgLogos:` frontmatter to any member file once HL7 membership is confirmed. The schema validates structure; the unit tests will catch malformed entries.
- **Accelerator logos:** Add additional entries to `orgLogos` with `cardBadge: false`. They appear on the listing card and detail page only.
